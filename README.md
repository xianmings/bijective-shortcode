# bijective-shortcode

6 位短码生成的三种方案对比:自增、hash 截断、模幂双射。

结论先行 —— **模幂双射把自增的"不重不漏"和 hash 的"杂乱无章"合到了一起**:
零碰撞由数论保证(不靠重试),输出不可枚举,而且可逆、无需额外维护映射表。

```python
from shortcode import BijectiveScheme

scheme = BijectiveScheme()          # 构造时随机生成密钥
a, b = scheme.encode(1), scheme.encode(2)
print(a, b)                         # 例如 'L8Ezph UpyVbK' —— 相邻 ID 毫不相干
print(scheme.decode(b))             # 2
```

> 密钥(p、q、E)每次构造都会重新随机生成,所以短码值本身不可复现。
> 生产环境要把密钥持久化,否则所有历史短码都会失效 —— 见[使用边界](#使用边界)。

---

## 问题

短链服务要把自增 ID 映射成定长短码。6 位 base62 的容量是 `62^6 = 56,800,235,584`,
约 568 亿 —— 存储层面非常宽裕,难点不在容量,而在**怎么映射**。

## 方案一:自增

```python
code = base62(identifier)
```

| 优点 | 缺点 |
|------|------|
| 零碰撞,天然一一对应 | **可枚举**:从 `hhhhhh` 试到 `hhhhhZ` 就能爬完全站 |
| 容量 100% 利用,码最短 | **暴露业务量**:两个短码相减直接读出记录数差 |
| B+ 树顺序插入,写入局部性好 | **可预测**:能推算未生成的码,甚至预占 |
| 不需要任何额外存储 | 短码可直接换算回 ID,ID 又常被内部系统引用 |

可枚举这条是致命的。抓到一个短码,把它 +1 就是下一条记录的短码;
抓到年初和年末各一个,相减就知道这一年的业务量。

## 方案二:hash 截断

```python
code = base62(hash(identifier) % 62**6)
```

| 优点 | 缺点 |
|------|------|
| 不可枚举,输出无规律 | **碰撞无法消除**,只能靠额外存表 + 检测 + 重试 |
| 同一输入稳定复现 | **不可逆**,还原必须查 `code -> url` 表 |
| 实现简单,无状态 | 重试会破坏"同一 URL 同一短码"的天然去重 |

关键在于:hash 是**射入**(into)而非**射到**(onto)。它是多对一的,
碰撞不是实现缺陷,是数学后果 —— 换更长的摘要只是把碰撞概率推低,推不到零。

实测:

| 短码长度 | 码空间 | 投喂 ID 数 | hash 碰撞数 | 生日碰撞理论值 |
|---------|--------|-----------|------------|--------------|
| 4 位 | 14,776,336 | 200,000 | 1,387 | ~1,353 |
| 6 位 | 56,800,235,584 | 1,000,000 | 8 | ~8.8 |

理论值按 `n² / 2M` 估算(n 为投喂量,M 为码空间),与实测吻合。

6 位码下每百万条撞 8 次听起来不多,但短链是长期累积的:到了 1 亿条,
期望碰撞数涨到约 8.8 万次,每一次都要靠存表和重试去救。

## 方案三:模幂双射

```python
y = x^E mod N        # 生成:x 是自增 ID,y 是短码数值
x = y^D mod N        # 还原:D = E^-1 mod λ(N)
```

其中 `N = p * q`(p、q 为素数),`λ(N) = lcm(p-1, q-1)`。

### 为什么零碰撞

对 `N = p * q`(p、q 为不同素数),由中国剩余定理 `Z_N ≅ Z_p × Z_q`,
映射 `x → x^E mod N` 在两个分量上独立作用。

在 `Z_p` 上:`Z_p*` 是阶为 `p-1` 的循环群,`x → x^E` 在其上是双射
**当且仅当** `gcd(E, p-1) = 1`(又 `0 → 0` 固定,不影响)。对 q 同理。

于是 `x → x^E mod N` 是 `[0, N)` 上的双射,当且仅当

```
gcd(E, p-1) = 1  且  gcd(E, q-1) = 1   ⟺   gcd(E, λ(N)) = 1
```

**每个输入恰好对应一个输出,不重不漏。** 这是定理,不是概率 —— 所以不需要
碰撞检测,也不需要重试。逆元 `D = E^-1 mod λ(N)` 给出还原:
`(x^E)^D = x^(ED) ≡ x (mod N)`。

代码里用 `EXHAUSTIVE_LENGTH = 3` 的容量穷举了全部 238,328 个输入来验证这个
性质,而不是抽样。

### 为什么看起来随机

模幂高度非线性。输入 +1,输出在整个 `[0, N)` 上无规律跳变 —— 相邻 ID 的短码
数值差通常在数十亿量级:

| ID 对 | 自增方案差值 | 模幂双射差值 |
|-------|------------|-------------|
| 1000 → 1001 | **1** | 7,863,400,891 |
| 1000 → 2000 | **1,000**(直接泄漏记录数) | 7,850,206,056 |

### 三个方案横向对比

| 维度 | 自增 | hash 截断 | 模幂双射 |
|------|------|----------|---------|
| 碰撞 | 无 | 有,需重试 | **无(数学保证)** |
| 可枚举 | 是 | 否 | **否** |
| 可逆 | 是 | 否 | **是** |
| 需额外存表 | 否 | 是 | **否** |
| 容量利用率 | 100% | <100% | 99.6% |
| 顺序写入局部性 | 优 | 差 | 差 |
| 生成速度 | 125 万/秒 | 57 万/秒 | 43 万/秒 |

速度数据来自 `demo.py`,本机单线程实测。模幂慢一些,但短码只在创建时生成一次,
后续命中走缓存,这个量级完全够用。

## 使用边界

这一节比上面重要 —— 用之前必须知道它做不到什么。

**它不是密码学强度。** `N` 只有 36 比特,是为了塞进 6 位短码才刻意选小的。
分解它只需要试除到 `sqrt(N) ≈ 238,000`,是毫秒级的事。所以:

- 它抗的是**枚举推断**(看到短码猜不出下一个、猜不出总量),不是**暴力破解**
- 一旦 `p`、`q` 泄漏,整个码空间可被完全枚举
- 要做真正的抗攻击,需要 128 位以上的 Feistel 网络,但那远超过 6 位码的容量

**密钥必须持久化。** 换密钥等于让所有历史短码失效。`(N, D)` 要当配置存起来,
不能在每次启动时随机生成。还原只需要 `N` 和 `D`,所以轮换时可以保留旧密钥用于解码。

**写入没有局部性。** 短码列做唯一索引时,插入是随机分布的,B+ 树页分裂比自增方案多。
规避办法是别把短码当主键 —— 内部仍然用自增 ID 做主键,短码只做外部标识。

**容量有上限。** `N ≤ 62^6`,用到 99.6%。码用满就得加长到 7 位。

**有不动点。** 满足 `x^E mod N == x` 的 x 会映射到自己,其中 `x=0` 和 `x=1`
(`1^E` 恒为 1)会让前两个 ID 得到 `hhhhhh` 这种退化短码。`BijectiveScheme` 默认带
`DEFAULT_SEED = 100_000` 的偏移绕开它们。偏移量本身不参与运算,只是把输入推离不动点。

## 延伸

这个方案是**保格式加密(Format-Preserving Encryption)** 的雏形。同一个思路下更成熟的做法:

| 做法 | 思路 |
|------|------|
| Knuth 乘法散列 | `f(x) = (x * a) mod 2^k`,a 取奇数时是双射,比模幂快得多 |
| Feistel 网络 | 多轮迭代,可以在任意目标区间上构造双射,是 FPE 的主流方案 |
| Hashids | 加盐的置换 + base62,不追求可逆性证明 |

模幂这条路的独特价值在于**逆元有闭式解**,还原不需要跑反向网络,
也不需要任何存储 —— 代价是模数必须由两个素数乘出来。

## 项目结构

```
shortcode/
├── base62.py        打乱字母表的 base62 编解码,定长输出
├── permutation.py   模幂双射核心:密钥生成、判定、双向映射
└── schemes.py       三种方案的统一封装,便于横向对比
demo.py              三种方案的实测对比(形态/碰撞/可猜测性/可逆性/性能)
tests/               23 个测试,含双射性质的穷举验证
```

## 运行

```bash
python demo.py                    # 对比演示
python tests/test_shortcode.py    # 跑测试(不需要 pytest)
pytest                            # 装了 pytest 也可以这样跑
```

无第三方依赖,标准库即可运行。需 Python 3.10+。
